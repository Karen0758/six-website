# Working agreements

- Preserve the Figma Make file and user-supplied source media. This repository is a separate implementation.
- Do not commit source video or generated `public/media` assets until the user chooses to publish them.
- Update `PROJECT.md` and `docs/ANIMATION.md` when timing, asset budgets, or deployment status changes.
- Before claiming completion, run a clean build and inspect the animation in a browser. Distinguish static checks from browser and live deployment checks.
