# 人物动画规格

## 左侧坐姿人物

- 输入：用户提供的 1256×732、24 fps、121 帧视频（本地素材，不入 Git）。
- 输出：52 张 628×586 灰度 WebP，12 fps，播放约 4.33 秒。
- 时间映射：原视频第 0–36 帧每 4 帧取一张；之后每 2 帧取一张。前段静坐时长约 0.8 秒。
- 画幅：整段使用固定倍率 1.35，并将人物和影子按统一坐标放入帧画布，避免逐帧放大造成头部出框和尺寸漂移。
- 影子：保留本次输入视频中的原始影子，不再追加人工连接线。
- 合成：灰度画面的白色在 Multiply 中保持底色，不预先给人物上粉色。
- 加载：只预载首帧；点击后最多 6 路并发加载该段其他帧。播放结束停在站姿。

## 后续两段

中间人物计划为转身面向观众，右侧人物计划为继续行走几步。各自独立成帧序列并按点击触发，不在首屏预载完整序列。接入时记录原视频、帧数、输出画幅、脚底基线、文件体积与浏览器目视验收结果。配置入口在 `src/config.ts`。

## 重建素材

```sh
python3 tools/build_seated_frames.py --video '/path/to/user-video.mp4' --output public/media/seated
```

需要本机 `ffmpeg` 和 Pillow。视频和生成媒体不入 Git。片源更换后，检查输出帧的头部留白、脚底位置、影子连续性和文件体积。
