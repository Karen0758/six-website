# 人物动画规格

> 10/27 本地改版：粉色「我们是谁」页保留原有波浪铺屏与人物动作。下一次下滑以 1.65 秒转入独立的「发起合伙人」页：米白纸纹从右侧沿弧形波浪推进，粉色弧线保留为下方岸边；上一页人物同步向下离场，黄色纹理竖带先出现，右侧柏树剪影随后显现。四条经历直接展示，不设置折叠；悬停、点按或滚动到经历时浮出淡粉印纹。再下滑才切到黄色「方法」。此说明仅针对独立本地预览副本。

## 左侧坐姿人物

- 输入：用户提供的无水印 1280×720、24 fps、73 帧视频（本地素材，不入 Git）。
- 输出：37 张 628×586 灰度 WebP，播放时从第 12 帧开始，按 18 fps 约 1.33 秒；WebP 质量 92，轻微锐化保留头发与衣料细节。首页仍显示第 0 帧坐姿。页面载入后后台预取这组帧；粉色铺满时开始动作。
- 时间映射：新视频完整覆盖，原视频每 2 帧取一张；开头静坐段约 0.8 秒。
- 画幅：整段使用固定倍率 1.35，并将人物和影子按统一坐标放入帧画布，避免逐帧放大造成头部出框和尺寸漂移。
- 首帧：保持逐帧图原始比例；首页静态人物保持原样。
- 影子与画面：保留视频原有的人物、鞋子和自然投影；不额外绘制连接线。无水印版跳过修复处理，整体上移少量以确保脚部完整。
- 合成：灰度画面的白色在 Multiply 中保持底色，不预先给人物上粉色。
- 加载：只预载首帧；点击后最多 6 路并发加载该段其他帧。播放结束停在站姿。

## 中间黄色人物

- 输入：用户提供的 756×1212、24 fps、73 帧本地视频。
- 输出：20 张 628×939 灰度 WebP，12 fps，约 1.58 秒；取原视频第 34–72 帧，每 2 帧取一张，以正面朝向帧定格。
- 画幅：20 帧、12 fps 和原视频第 34–72 帧的抽帧顺序不变；全身图以首页人物约 58% 的显示倍率放在画面中间偏左，头顶和脚底保持原有高度；黄色章节文字整体下移。
- 合成：中间卡片被点击后，黄色纸纹从屏幕中心以圆形范围扩展；人物帧白底作为正片叠底中性色，人物和原视频影子保留灰度。
- 资源：黄色纸纹取自首页背景中的芥末黄色纸面；视频和生成帧留在本地，不入 Git。
- 加载：中间人物悬停/聚焦时预载；点击后最多 6 路并发加载。播放结束停在正面帧。

## 首页触发

- 左侧人物卡触发粉色波浪与站起动作；揭幕边缘沿斜线向左上推进，波浪曲线越过右侧视口并覆盖底边，避免闭合边切出三角。
- 站起序列从首页原始画幅和人物落点平滑放大至 703×656，并将站姿与首页人物区域对齐；脚底基线保持不变，阴影保留在原帧中。
- 中间黄色人物卡独立触发黄色圆形揭幕，不与粉色场景自动串联。
- 除点击人物卡外，向下滚轮或触屏上滑也可依次触发粉色、黄色、米色三段；向上滚轮或触屏下滑按相反顺序逐页返回首页。转场期间忽略新手势，避免一次滑动跳过页面。

## 手机端布局

- 视口宽度不超过 700px 时，背景采用独立的 390×844 构图坐标：粉色曲线位于下半屏，黄色竖条贴近中央。桌面构图及动画坐标保持原有值。
- 首屏标题、加入入口与两位人物小字分置在画面上方及人物旁；三组逐帧人物使用独立手机画布位置，保持头部、脚部和影子可见。
- 章节正文位于画面上方，人物动画位于下方。米色转场结束时卸载黄色和粉色离场图层，避免窄屏残留色块。
- 手机端正文改为直接叠在各场景纸纹上，去掉不透明卡片与边框；常见竖屏尺寸可完整显示，较矮视口仍可在文字区域滚动阅读全文，人物保持在下方。
- 手机端“我们是谁”和“方法”正文加大并下移；“如何加入”正文增大行距，邮箱地址改为显示邮件图标与“发邮件”，点击使用 `mailto:` 打开设备配置的邮件应用。
- 最后一页右下角在手机端和桌面端均提供“返回主页”按钮；桌面端也可以向上滚轮逐页返回。粉色第一站、合伙人页等正文区域未滚到边界时，滚轮和触摸滑动先滚动正文；滚动至边界的同一次滚轮手势不会立即翻页。
- 黄色圆形揭幕在窄屏使用等比 SVG 缩放，避免固定画布随手机宽高比被拉成椭圆。人物旁方向箭头由 SVG 路径绘制，避免系统把字符替换成 emoji。
- 首页中文标题、章节衬线标题和翻页提示使用同一份 Noto Serif SC 500 子集字体，包含“继续下滑”“返回主页”的全部字形，避免个别字退回系统字体；正文使用 Noto Sans SC 400 子集字体。标题两行使用同字号，手机和桌面不再依赖各自的系统字体回退。

## 章节文字

- 第一位人物及其“01 我们是谁”小字 → 粉色动画及“我们是谁”；中间黄色人物及其“02 方法”小字 → 黄色动画及“方法”；标题下方“加入我们”按钮和米色区域 → 第三段行走及“如何加入”。右上角不再显示“方法”“加入”入口；第三位人物的静态图不在首页出现。
- 粉色和黄色人物动作在各自转场开始时同步启动；粉色文字在转场进度 65% 时开始，黄色文字在 1.5 秒转场的进度 2/3 时（约 1 秒后）逐项淡入。粉色转场为 1.2 秒；米色场景中黄色向左、粉色和首页两位人物向下同时离场，统一为 0.7 秒。米色人物在首页退出完成后开始进场，进场约 2.5 秒（原速的 0.8 倍）。
- 文字开始后每行淡入 320 毫秒，行间隔按文字行数动态计算；开启减少动态效果时，正文立即显示。
- 章节文字过长时可以在文字区域内滚动；滚到末尾再向下滑动或滚动，会进入下一段人物动画。
- 粉色「我们是谁」与「发起合伙人」页在正文末尾提示继续下滑；黄色章节转场完成后，在画面右下方显示“继续下滑”与向下箭头。最后的米色章节不显示下一页提示。

## 首页可视编辑

本地开发预览提供“编辑页面”控制器，可以从画布拖动当前选中的任意图层，并调整背景、左下人物、中央人物、右侧隐藏触发区域、粉色揭幕层和标题组的位置、缩放与层级；人物图层可单独调整横向和纵向拉伸。也可修改四项首页文案。新版默认构图使用独立的本地存储键 `six-homepage-visual-editor-v2`，旧版编辑数据仍保留在原键中；生产包使用代码默认值，不包含控制器。

## 右侧行走人物

- 输入：用户提供的无水印 852×1080、24 fps、约 4 秒视频；原始视频保存在本机，不进入 Git。
- 输出：49 张 512×825 透明 WebP，按 19.2 fps 播放，进场动作约 2.5 秒（原速的 0.8 倍），总体约 0.96 MB。首页不加载右侧定格图；用户点击“加入”或米色区域后才预载动作帧。
- 动作：点击后黄色纸块向左退出，粉色纸块与首页两位人物向下退出；首页退出完成后，第三位人物的逐帧图从左侧进入，在画面中央停住。
- 画面：背景使用独立米色纸纹图；人物按正片叠底合成。人物大小和落点按用户提供的 JSON 布局对齐；裁切保留双脚完整，并清理鞋旁分离的地面碎线。
- 加载：最多 6 路并发预载。49 张逐帧图合计小于 2.5 MB。
- 进场：首页各色块同时离场（0.7 秒）后，人物从左侧进入；首帧预载不阻塞动画启动。

## 重建素材

```sh
python3 tools/build_seated_frames.py --video '/path/to/clean-seated-video.mp4' --output public/media/seated --clean-source
python3 tools/build_walk_frames.py --video '/path/to/clean-walk-video.mp4' --clean-source
```

需要本机 `ffmpeg`、Pillow 和 OpenCV（`python3 -m pip install -r tools/requirements-media.txt`）。视频和生成媒体不入 Git。片源更换后，检查输出帧的头部留白、脚底位置、影子连续性和文件体积。
