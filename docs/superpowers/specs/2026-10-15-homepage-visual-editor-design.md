# SIX 首页可视化编辑器设计

## 目标

在当前 SIX 首页预览中提供一个仅供编辑使用的控制器，让用户可以手动调整首页可见内容。保持正常官网画面简洁；左下人物在首页静止画面和站起动画中都适度放大，脚底与人物主体仍对齐原首页位置。

## 方案

采用嵌入首页的编辑模式，而不创建独立管理页。开发预览提供“编辑页面”入口，开启后在页面侧边显示控制器；生产构建不包含编辑入口和控制器。用户日常通过当前页面直接查看和调整，避免维护两套预览。

## 编辑对象与操作

可选图层包括背景、左下人物、中央人物、右侧人物、粉色揭幕层，以及标题组。图层列表显示当前前后顺序；选择图层后可调整横纵位置、缩放和前后顺序。左下人物在编辑模式支持画布内直接拖动，其余图层至少可通过位置字段调整。文本编辑覆盖品牌副标题、主标题、介绍段落和按钮文字；文字位置和层级由标题组控制。

所有位置和比例以现有 1676×939 设计坐标为基准，再映射到视口。左下人物首页尺寸默认约放大 15%，围绕人物主体与脚底基线调整，站起时从该落点平滑进入已配置的较大站姿画幅。人物序列、正片叠底、影子和既有波浪动画继续使用原媒体与渲染流程。

## 状态与保存

编辑值以独立的可序列化配置保存，默认值与首页内容分开定义。仅本地浏览器保存编辑状态，刷新后保留；提供恢复默认值和导出 JSON 两种操作。生产页面使用代码内默认值，不读取编辑器的本地存储，也不显示编辑器，因此本地调整不会自动改变线上官网。

## 结构边界

- 新增编辑器面板组件，负责图层选择、位置/缩放字段、前后顺序、文本字段、恢复与导出。
- 页面渲染读取统一的可视配置，使编辑值即时反映到画面与点击交互层。
- 新增配置读写辅助函数，负责默认值合并、localStorage 读写和 JSON 导出；存储不可用或内容格式无效时回退到默认配置并继续显示页面。
- 编辑器状态通过明确的开发模式条件隔离，生产构建不包含可操作入口。

## 验收

1. 开发预览可开启和关闭编辑器；普通首页交互不受影响。
2. 调整图片位置、缩放和层级时画面即时更新；调整文字时标题、介绍和按钮即时更新。
3. 左下人物在首页和站起场景均比原先约大 15%，脚底基线稳定，视觉中心仍对应首页左下位置。
4. 刷新开发预览后本机编辑值保留；恢复默认值和 JSON 导出可用。
5. 生产构建没有编辑入口或控制器，并使用项目默认内容。
6. 自动化测试覆盖默认配置、编辑值的约束/合并、保存恢复、文本/图层变更；构建成功后在浏览器检查编辑与人物交互。

## 不在本次范围

不创建账号、云端协作或在线发布接口；不编辑或重生成图片、视频素材；不改变中间和右侧人物动画逻辑；不增加手机端专属布局编辑。
